# Koi asset

Method: built-in imagegen tool, using the user's blue-and-white butterfly koi video frame as the anatomy and fin reference.

Runtime asset: `public/assets/koi-coral-v2.png` (1774 × 887 RGBA, transparent background).

This is a photographic-style texture animated on a deforming Three.js surface; it is not a full volumetric fish model. The Canvas fallback uses the same steering and spine, and the final DOM fallback continues to follow the cursor.
